# Demo Broken App

A simple Express.js API for managing users and tasks.

## Setup

```bash
npm install
npm run dev
```

## API Endpoints

- `GET /api/users` — List users
- `POST /api/users` — Create user
- `GET /api/tasks` — List tasks
- `POST /api/tasks` — Create task
